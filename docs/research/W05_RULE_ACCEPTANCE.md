# W-05 · 首版默认 Normalize 规则评审结项

**评审日期**：2026-11-04  
**评审确认**：维护者明确反馈“全部规则评审通过”。  
**结项范围**：36 条初始候选的**审查结论和首版去留决策**均已批准；**不是批准将 36 条 CSS 声明全部实现**。  
**对应工作项**：[W-05 Issue #6](https://github.com/adui-studio/normalize.css/issues/6)

## 1. 首版准入决定

首版默认 Normalize 只保留 **R-003** 一条已实现的规则：

```css
b,
strong {
  font-weight: bolder;
}
```

- **准入原因**：已在目标旧版 Chromium/Chrome 120 观察到 `bold` 与 `bolder` 在父级字重为 600/700 等情况下的真实计算结果差异，且与 WHATWG 默认渲染建议一致，见 [R-003/R-004 证据卡](RULE_EVIDENCE_R003_R004.md) 和 [本机运行记录](LOCAL_BROWSER_RUN_20261104.md)。
- **实现范围**：仅 `b` 与 `strong`，无其他产品 CSS；见 [src/normalize.css](../../src/normalize.css)。
- **已完成回归**：W-06 由维护者正式验收归档（见 [归档索引](W06_ACCEPTANCE_INDEX.md)）；Tailwind Preflight、UnoCSS Reset 在 Chrome 156 的构建与静态对照有实测证据。W-06 管理验收完成不自动生成所有目标浏览器版本的逐项可复核 PASS。
- **保持原生语义**：默认不设置根字号、全局主题/滚动条、通用间距归零、全局焦点隐藏、按钮外观或系统偏好强制覆盖；不使用默认 `@layer`。这些原则保持不变。

## 2. 全 36 条规则的评审结论

以下结论沿用 [RULE_REVIEW.md](RULE_REVIEW.md) 既有分类和研究资料，维护者本轮批准的是**该分类与首版实施边界**，不是给未实测候选添加不存在的浏览器证据。

| 结论 | 规则 ID | 数量 | 首版处理 |
| --- | --- | ---: | --- |
| **默认 Normalize 准入** | R-003 | 1 | 已实现，唯一正式 CSS 声明 |
| **暂缓 / 不采纳默认字号统一** | R-001、002、004、005～016、018、027、028、035 | 19 | 保留原生行为；若未来有新证据，另行评审 |
| **可选模块设计** | R-020～026、031 | 8 | 属于 Reset / Forms / A11y 远期方向；**首版不提供该模块入口** |
| **排除默认** | R-017、019、029、030、032～034、036 | 8 | 不加入默认 CSS；重点避免损坏 Dialog、hidden、焦点、系统偏好及全局视觉 |
| **合计** | R-001～R-036 | **36** | **全部已审定去留，无待决默认新增规则** |

**R-004 明确决定**：保留浏览器对 `code`、`kbd`、`samp`、`pre` 的默认等宽字体与字号；默认不使用 `font-size: 1em`、强制字体栈或 `monospace, monospace` 绕过用户等宽字号偏好。未来如需统一代码排版，只能按新的可选能力另行评审。

**其他候选**：R-007～011 等历史补丁仅因上游曾修复过某问题而被纳入研究，当前缺少新规则必要性证据，维持暂缓；R-020～026 与 R-031 即使是可选设计，也不能被本次通过解释为已实现、已导出或进入首版包。

## 3. 证据与验收等级

- **已验证并实现**：R-003 有特定浏览器版本的差异复现、静态包构建与有限生态/Reset 对照；W-06 后续管理验收由维护者明确完成。
- **评审批准，但未实现**：其余 35 条的**首版分类与不新增决定**；不是对每条候选完成了独立浏览器实测，也不是批准其 CSS 代码。
- **跨浏览器边界**：最低测试目标 Chrome/Edge 120、Firefox 121、Safari 17.2 及移动版本的正式支持声明，仍按 [浏览器支持边界](BROWSER_REVIEW.md) 引用可复核的环境证据；评审通过不代表 npm 已发布。
- **后续流程**：W-05 已按维护者通过的评审结论结项（Issue #6 Closed — completed）；W-02 的来源证据维护和 W-07 的发行前文档/许可证/公开文件审核是独立范围，不因此自动关闭或发布。
